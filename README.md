# Sistema de Gestión de Productos

Proyecto universitario desarrollado en PHP con base de datos MySQL.

---

## ¿De qué trata?

Este sistema permite administrar la información de un negocio pequeño desde el navegador. Incluye registro de usuarios con inicio de sesión, y módulos para gestionar productos, categorías, proveedores, clientes, facturas y ventas.

---

## Módulos del sistema

| Módulo | Qué hace |
|---|---|
| Usuarios | Registrar, ver, editar y eliminar usuarios del sistema |
| Categorías | Clasificar los productos por tipo |
| Proveedores | Registrar las empresas que suministran los productos |
| Productos | Agregar productos con precio, categoría y proveedor |
| Clientes | Registrar los clientes que realizan compras |
| Facturas | Crear facturas asociadas a un cliente |
| Ventas | Registrar qué productos se vendieron en cada factura |

---

## Cómo instalarlo

1. Tener instalado [XAMPP](https://www.apachefriends.org/) con Apache y MySQL activos.

2. Copiar la carpeta del proyecto dentro de `C:\xampp\htdocs\`.

3. Abrir **phpMyAdmin** (`http://localhost/phpmyadmin`) e importar el archivo `config.sql` para crear la base de datos.

4. Abrir el navegador e ir a:
   ```
   http://localhost/formulario_productos/index.html
   ```

5. Registrarse y comenzar a usar el sistema.
